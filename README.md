# Strudel Craft

Recipes for sounds, harmony, rhythm, arrangement and feel in [Strudel](https://strudel.cc), filterable by concept, with a live player, plugin reference, best practices and a compose-from-labels page. Static site in `site/`, deployed to GitHub Pages by `.github/workflows/pages.yml`.

Strudel itself (AGPL-3.0-or-later) is loaded unmodified from unpkg (`@strudel/web` 1.3.0); it is not vendored here.
