# DnB, electro, house / techno / trance / big room: references and what each taught

Owner: `daw-sme`. Issues #121 (references, genre targets), #122 (components, forms, dovetails), #123 (feel templates), #124 (tutorial
track). Pack `glyphcore/dnb-electro` (CC0-1.0). Shared EDM foundations (sidechain moves, risers, impacts, roll and filter-build tables,
OTT-style squash, the 104-bar EDM form) are **not** repeated here: they live in `glyphcore/edm` and docs/EDM_REFERENCES.md, and this pack
uses them (section 5). Everything below is re-derived in our own CC0 data; no preset, sample or code is copied from any source.

Marking: **(S)** sourced (the claim is what the linked page says), **(M)** measured here with the headless CLI (numbers in the issues and
docs/RACK_STANDARD.md), **(D)** our design decision with its reason, **UNVERIFIED** = not confirmed against a primary source.
Many genre pages are production blogs, sample-pack shops or course pages; where only such a source exists, the number is a convention to
start from, not a standard, and the genre targets mark it (G) = guess.

## 8. Design decisions that no source fixes (D)
- **Key**: F minor for every component so they combine; F1 = 43.7 Hz sits in the sub zone of all three genres; chords Fm9 - Dbmaj9 - Bbm9 - Cm7 (liquid), Fm - Db - Eb - Cm (electro), Fm - Db - Ab - Eb (house / trance).
- **Grid**: one cycle = one bar of 4/4, 16 steps; tempo by `setcpm(bpm/4)`. Halftime is a pattern (snare on beat 3), never a tempo change.
- **Breaks**: synthesised kits only; the chop order (`dnb.chops`, `dnb.chopsWild`) is the same data for a synthesised and a sampled break.
- **Low end**: sub (mono sine, 25-250 Hz) + mid layers (reese / neuro from 100 Hz) = a multiband split by layers, no crossover filters; bus glue on the mid layers only.
- **Grooves**: DnB swing at most 54 % (past about 55 % 16ths read as UK garage shuffle); house shuffle 56 %; trance, electro house and big room tight (0.5 % jitter) because gates and pumps are on the grid.
