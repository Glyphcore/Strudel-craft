# glyphcore/drumkits

Big Rusty Drums (https://github.com/sfzinstruments/karoryfer.big-rusty-drums, Karoryfer Samples) and Gogodze Phu Vol II (https://github.com/sfzinstruments/karoryfer.gogodze-phu-vol-ii, Karoryfer Lecolds), both CC0 1.0 Universal, LICENSE read at the pinned commits (see LICENSE.md).
Referenced, not hosted: inline maps of file URLs pinned to commits f07ce00 and 69a0274 (raw.githubusercontent.com, CORS *, fetch check 2026-11-17). Big Rusty files are FLAC (Chrome, Firefox and Safari decode FLAC); Gogodze files are WAV. One close-mic velocity layer, up to 4 round robins (`s("brd_kick:2")`).
Sounds: brd_kick, brd_snare, brd_hat_closed, brd_tom, brd_ride; gog_kick, gog_snare, gog_hat_closed, gog_hat_open, gog_tom_low, gog_tom_mid, gog_tom_high.
Nothing is fetched until a program names one of the sounds. Recipes: brd-groove, gogodze-groove, gogodze-toms. Rebuild with tools/instruments/build_sources.py.
