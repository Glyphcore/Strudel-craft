# glyphcore/edm: licence

All content of this pack (racks-*.json, atoms-*.json, feel-*.json, this README) is authored for this repo and dedicated to the public
domain under **CC0-1.0** (https://creativecommons.org/publicdomain/zero/1.0/). No attribution is required.

The pack ships no audio and plays no samples: every sound is synthesised by Strudel's superdough (oscillators, noise, filters,
envelopes, FM, distortion). Techniques are re-derived from public documentation and general practice (sources and what each one taught:
docs/EDM_REFERENCES.md); no third-party presets, samples or code are copied.
