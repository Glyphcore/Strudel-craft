# glyphcore/vcsl

Versilian Community Sample Library (https://github.com/sgossner/VCSL, Versilian Studios LLC, Sam Gossner), CC0 1.0 Universal (LICENSE at the terms URL).
Referenced, not hosted: the map is Strudel's own https://strudel.b-cdn.net/vcsl.json (128 sounds, files on raw.githubusercontent.com). Fetch check 2026-11-17: map and a sample file answer 200 with access-control-allow-origin: *.
Nothing is fetched until a program names one of the sounds (e.g. s("marimba")). Offline: audio from raw.githubusercontent.com is runtime-cached in sc-banks-1 on first play; the map host is not (see site/README.md).
Recipes: vcsl-marimba, vcsl-harp-pluck, vcsl-drum-kit.
