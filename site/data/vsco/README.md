# glyphcore/vsco

VSCO 2 Community Edition (https://github.com/sgossner/VSCO-2-CE, Versilian Studios LLC, Sam Gossner), CC0 1.0 Universal.
Referenced, not hosted: `sources/sources.json` holds an inline map of file URLs pinned to commit 440300901dfe9275fd84e0b7763af1f8443ae62e (raw.githubusercontent.com, CORS *, fetch check 2026-11-17). One file per note, a mid dynamic; sustained articulations (vibrato where the library has it).
Sounds: vsco_violin, vsco_viola, vsco_cello, vsco_bass, vsco_trumpet, vsco_horn, vsco_trombone, vsco_tuba, vsco_flute, vsco_oboe, vsco_clarinet, vsco_bassoon (note names are scientific pitch, c4 = middle C).
Nothing is fetched until a program names one of the sounds. Recipes: vsco-strings, vsco-brass, vsco-woodwinds. Rebuild the map with tools/instruments/build_sources.py.
