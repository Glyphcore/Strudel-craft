# Audit sample kit licence

The files produced by `make_samples.py` (the `kit/` folder) are synthesized from fixed formulas and a fixed random seed by this repository's own code. No recording, sample library or drum-machine sound was used or imitated. CC0 1.0 Universal: no rights reserved, use freely. The `RolandTR909_` / `RolandTR808_` folder names exist only so that `.bank("RolandTR909")` resolves offline; they are names, not the machines' sounds.
